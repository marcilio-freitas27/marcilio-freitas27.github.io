Editor web experimental via Web MIDI + SysEx

1. Conectar

Use Chrome ou Edge. O navegador pedirá permissão para MIDI/SysEx.

2. Modo de escrita

Por segurança, a interface começa apenas monitorando. Ative a escrita para enviar parâmetros à RAM do pedal.

3. Presets

Escolha um ponto de partida e ajuste ao vivo.

4. Ajuste fino

Os sliders usam a faixa MIDI 0–127.
